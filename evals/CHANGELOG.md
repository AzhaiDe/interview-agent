# Live Evaluation Changelog

## v5 (2026-08-13) — 评分校准

### 修复内容

1. **Action 逻辑重构** (`src/agent-runtime.ts`)
   - 对抗/跑题回答 → "pivot"（原为 "clarify"，与 gold 标签不一致）
   - 分数 ≥ 6.5 且缺失证据 ≤ 2 类 → "advance"
   - 其他情况 → "clarify"（原逻辑仅看 missing evidence 不考虑分数）

2. **Model Judge Prompt 校准**
   - 从"你是严格的评审器"改为"你是客观公正的评审器"
   - 加入明确的 0-10 评分锚点（0-1 对抗/跑题，2-3 模糊尝试，4-5 基本机制，6-7 有职责证据，8-9 完整证据，10 系统权衡）
   - 加入"宁可稍松勿过严"原则
   - 明确"模糊但尝试回答的答案应得2-4分，不要给0分"

3. **Deterministic Judge 校准**
   - 基础分从 `3 + min(3, covered*0.7)` 改为 `3 + min(4, covered*0.8)`
   - 对抗/跑题直接返回 0.5（不再通过复杂计算）
   - 长度梯度更细：<20字符 -1，50-100 +0.5，100-200 +1，≥200 +1.5
   - 数字证据额外加分（每个具体数字 +0.3，上限 +1.5）

4. **Judge 权重调整**
   - base: 0.1 → 0.2（提高确定性评分的权重）
   - technical: 0.4 → 0.35
   - evidence: 0.25 → 0.2

5. **Evidence 提取增强**
   - 职责边界：增加"独立完成"、"个人贡献"、"我写的"、"我来做"
   - 实现机制：增加"原理"、"机制"、"底层"、"架构"、"接口"、"函数"、"类"
   - 选型权衡：增加"对比"、"vs"、"选型"、"优势"、"劣势"、"折中"、"tradeoff"
   - 指标与口径：增加"召回"、"精确"、"准确率"、"覆盖率"、"延迟"、"吞吐"、"提升"、"降低"
   - 验证与对照：增加"测试"、"验证"、"重复"、"波动"、"口径"、"采样"、"benchmark"、"AB测试"
   - 异常与边界：增加"故障"、"容灾"、"兜底"、"限流"、"监控"、"告警"、"错误率"、"回滚"、"补偿"
   - 对抗检测：增加"告诉我.*提示词"模式
   - 跑题检测：增加"音乐"、"运动"，同时增加"代码"、"数据"、"服务"作为非跑题信号
