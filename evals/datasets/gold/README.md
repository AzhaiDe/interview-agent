# Gold Data Pipeline

This directory contains the evaluation gold data pipeline. Gold labels require
independent human annotation per `GOLD_BUILD_PROTOCOL.md`.

## Contents

### trajectories.jsonl
Complete interview sessions exported from the SQLite database via
`npm run eval:collect`. Each trajectory includes full turn-by-turn
conversation, evaluation outcomes, and annotation placeholders.

### interview-candidates.jsonl
Gold-candidate labels generated by `npm run eval:gold`. Each entry pairs
a real interview turn with:
- `_modelScore/_modelAction`: what the system produced
- `_suggestedLevel/_suggestedScoreRange/_suggestedAction`: KB-based heuristic
- `annotation.annotator1/annotator2/adjudicated`: fields for human input

## Pipeline

```
eval:collect → trajectories.jsonl
     ↓
eval:gold   → interview-candidates.jsonl
     ↓
  2+ independent annotators fill annotation fields
     ↓
  agreement check (Cohen's κ ≥ 0.70)
     ↓
  adjudication → promoted to gold/*.jsonl
     ↓
  manifest hash update
```
